Getting started
---------------
1. Clone the repository:

   git clone https://github.com/soyama06/Soyamagqaabazapart3.git
   cd Soyamagqaabazapart3

2. Open the project in your browser:
   - Double-click index.html (if present) or
   - Serve locally with a simple HTTP server:
     - Python 3: python -m http.server 8000
     - Node (install live-server): npx live-server

3. Edit files in the repository (HTML/JS/CSS) and refresh the browser to see changes.
