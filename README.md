JavaScript Implementation
JavaScript was used extensively throughout the website to provide interactivity, improve user experience, and handle form submissions.

EmailJS Integration
The website uses EmailJS to process form submissions without requiring a server-side language. EmailJS allows information submitted through the forms to be sent directly via email.

Booking Form Functionality
The booking form:
-Uses EmailJS to send booking information.

-Displays success and error messages to the user.

-Automatically resets the form after successful submission.

Contact Form Functionality
The contact form:

-Validates and processes user input.

-Submits data asynchronously using EmailJS.

-Displays a toast notification when a message is successfully sent.

-Resets the form after submission.

-Provides error handling and debugging information when submission fails.

Enquiry Form Functionality
The enquiry form:

-Captures customer enquiries.

-Uses EmailJS to submit enquiries without reloading the page.

-Displays confirmation notifications upon successful submission.

-Includes error handling for failed submissions.

AJAX-Based Form Submission
AJAX techniques were implemented through EmailJS, allowing forms to submit data asynchronously. This improves user experience by:

-Preventing page reloads.

-Providing immediate feedback.

-Allowing users to remain on the current page after submission.

Toast Notifications
A custom toast notification system was developed to:

-Display confirmation messages.

-Improve user feedback.

-Provide non-intrusive status updates after form submission.

Service Search Function
JavaScript was used to create a dynamic search feature that:

-Filters services in real time.

-Searches through available service cards.

-Updates displayed results as the user types.

Dynamic Content Generation
Service information and pricing data are stored in JavaScript arrays and rendered dynamically. This:

-Reduces repetitive HTML code.

-Makes content easier to maintain.

-Allows service cards and price lists to be generated automatically.

Image Gallery Functionality
JavaScript was implemented to:

-Open service images when selected.

-Create an interactive viewing experience.

-Improve navigation of gallery content.

Error Handling
Error handling mechanisms were included throughout the application to:

-Detect submission failures.

-Log error information for debugging.

-Notify users when actions cannot be completed successfully.
CSS Implementation
CSS was used to create a modern, responsive, and user-friendly design.

Layout and Structure
-Flexbox was used for navigation and page layouts.

-CSS Grid was used to display service cards responsively.

-Containers were used to maintain consistent page widths.

Responsive Design
Media queries were implemented to ensure the website adapts to different screen sizes, including mobile devices and tablets.

Navigation Styling
Custom styling was applied to:

-Navigation links.

-Hover effects.

-Sticky header functionality.

Form Styling
Forms were styled to:

-Improve usability.

-Provide clear input fields.

-Maintain a professional appearance.

Card Components
Service cards were styled using:

-Box shadows.

-Rounded corners.

-Responsive layouts.

-Image optimisation techniques.

Toast Notifications
CSS animations and transitions were used to create smooth toast notification effects.

Lightbox Styling
Custom CSS was used to create a full-screen image viewing experience through the lightbox component.

Footer and Page Structure
Flexbox was used to ensure the footer remains at the bottom of the page regardless of content length.
